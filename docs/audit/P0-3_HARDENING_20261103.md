## 2. 已修复内容（本轮全部含测试）

### 2.1 D1 · 脚本审计改为"构造级拒绝 + 全分隔符切段"

- 新增 `SCRIPT_FORBIDDEN`：`$` 反引号 `>` `<` 换行回车 NUL —— 单元级拒绝，不给 shell 任何二次解释的机会。
- 切段集合从 `&& || ;` 扩到 `&& || ; | &`（先吃掉合法的 `&&`/`||`，剩下的单 `|`/`&` 才是真管道/后台）。
- `node --test` 边界从 `\b` 收紧到 `(\s|$)`，消掉"`node --test=1` 前端放行、Rust 拒绝"的镜像漂移。

### 2.2 D2 · 只读 git 的三道不可关闭加固

`run_allowed` 在 spawn 前调用 `effective_argv`，对 `git` 强制：

- 统一前置 `-c core.fsmonitor=false`（挡 `git status` 的 hook 执行）；
- `diff` 追加 `--no-textconv --no-ext-diff`（挡 `diff.*.textconv` / `diff.external`）；
- 环境隔离：`GIT_CONFIG_NOSYSTEM=1`、`GIT_CONFIG_GLOBAL=<空设备>`、`GIT_CONFIG_SYSTEM=<空设备>`、
  `GIT_TERMINAL_PROMPT=0`、`GIT_PAGER=cat`、`GIT_OPTIONAL_LOCKS=0`。
- 写侧同步：`fsx::write` 对首段为 `.git`（大小写不敏感、`/` 与 `\` 都算）**整目录拒绝**。

   → **已修（`6edb112`）**：`fsExists` 不再吞错，校验失败与备份失败均中止写入。
